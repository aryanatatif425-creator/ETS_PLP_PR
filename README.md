# Ekstraktor CRUD Matrix SQL

Proyek ini adalah implementasi *source-to-matrix extractor* berbasis teknik penerjemah bahasa (*compiler/interpreter*) untuk menganalisis skrip SQL dan mengekstrak matriks operasi **CRUD** (*Create, Read, Update, Delete*) pada setiap tabel, mendeteksi penggunaan kolom, serta melaporkan diagnostik sintaks dan resolusi *scope*.
